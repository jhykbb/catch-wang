# 밸런스 시뮬레이션 결과

- 판 수: 인원별 3000판 (혼합 성향) + 4성향 대결 3000판
- 설정: 시작 자금 10,000원, 20라운드, 시드 7
- AI 성향은 매 판 자리마다 무작위 (혼합), 또는 4성향을 한 명씩 (대결)
- 규칙 숫자는 `GameConfig.cs` 기본값 (RULES.md v0.2) 그대로
- 다시 만들기: `cd tools/Simulator && dotnet run -c Release -- --games 3000 --seed 7 --out ../../game-design/SIMULATION.md`
- 주의: AI의 판단 수준에 따라 결과가 달라진다. 숫자는 "규칙끼리 비교"용으로 본다.
